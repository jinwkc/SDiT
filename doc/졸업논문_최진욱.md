국문초록
  최근 몇 년 동안, 인공지능 및 딥러닝 분야에서는 많은 데이터와 강력한 컴퓨팅 성
| 능을  활용한  |          | 모델의  발전이   |      | 지속적으로  |      | 이루어지고     |         | 있다.  | 또한,    | 빅  데이터의  |     | 축적과  |
| -------- | -------- | ---------- | ---- | ------ | ---- | --------- | ------- | ---- | ------ | -------- | --- | ---- |
| 하드웨어의    |          | 발전은  딥러닝   | 모델의  |        | 규모를  | 키우고       | 복잡성을    |      | 증가시키는  |          | 데   | 기여하였 |
| 다. 이높는   | 성은  능정과  | 확도제를  공하지만 |      | 동시모에   | 델크의  | 기계와,  요산  | 사구  항도  |      |        |          |     |      |
크게 증가시키는 문제를 야기했다.
  이러한 문제를 해결하기 위해 모델 압축 기법이 중요한 연구 주제로 떠오르게 되었
| 으며, 모델 압축은 딥러닝 모델을 보다 작고 경량화된 형태로 변환하여,  |     |                |          |     |      |        |      |          |     |      | 모델 크기를  |        |
| ---------------------------------------- | --- | -------------- | -------- | --- | ---- | ------ | ---- | -------- | --- | ---- | ------- | ------ |
| 줄이고                                      | 추론  | 속도를  향상시키는 것을  |          |     | 목표로  | 연구된다.  |      | 이를 통해    |     | 제한된  |         | 자원을  가 |
| 진  환경에서도                                 |     | 효율적인           | 딥러닝 실행을  |     |      | 가능하게   | 한다.  | 본 연구에서는  |     |      | 모델      | 압축  기  |
법인  지식  증류(Knowledge  Distillation),  가중치  가지치기(Weight  Pruning),  양자화
(Quantization)와  같은  대표적인  모델  압축  기법을  분석하고  비교한다.  이  중에서도
| Teacher  | 모델과  | Student  |     | 모델  | 간의  | 지식  | 전달을  | 통해  | 작은  | 크기의  |     | 모델에도  |
| -------- | ---- | -------- | --- | --- | --- | --- | ---- | --- | --- | ---- | --- | ----- |
Teacher 모델의 정확도와 특성을 전달하는 방법인 지식 증류 기법이 가장 우수한 성
능을 보여주었다.
|   또한,  | 최근에는  | 컴퓨터  |     | 비전  | 분야에서  | 기존의  |     | 컨볼루션  |     | 레이어를  |     | 대체하는  |
| ------ | ----- | ---- | --- | --- | ----- | ---- | --- | ----- | --- | ----- | --- | ----- |
Transformer 기반의 모델인 ViT(Vision Transformer)가 주목을 받고 있으며, ViT 모
| 델은  Transformer  |     | 아키텍처를  |     | 활용하여  |     | 이미지  | 데이터를  |     | 처리하며,  |     | 뛰어난  | 성능을  |
| ---------------- | --- | ------ | --- | ----- | --- | ---- | ----- | --- | ------ | --- | ---- | ---- |
보여주고 있다. 그러나 ViT 모델은 많은 파라미터와 높은 데이터 요구량으로 인해 모
델 크기와 학습 비용이 증가하는 단점을 지닌다.
|   따라서,  | 본   | 연구에서는  | ViT  | 모델의  | 단점을  | 극복하고  |     | 적은  | 데이터로도  |     | 높은  | 성능을  |
| ------- | --- | ------ | ---- | ---- | ---- | ----- | --- | --- | ------ | --- | --- | ---- |
달성할  수  있는  새로운  모델인  SDiT(Self-Knowledge  Distillation  image
Transformer)을 제안한다.

(Bottleneck Block)을 구성한다. 하지만, 자기 지식 증류에서 병목 블록을 구성한 이
유는 파라미터 수 감소 효과와 효율적인 표현 학습 지식 전달 강화를 위해 사용된다.

| 서  학습을  |     | 진행을  하기에  | SDiT의  |     | 보조  분류기에서는  |     | 추가적인  | 병목  | 블록  | 또는  |

$$
\begin{aligned}
L_{\mathrm{TotalWithoutFeature}}
&= \sum_{i=1}^{C} \mathrm{loss}_i \\
&= \sum_{i=1}^{C} \Bigl((1-\alpha)\,\mathrm{CrossEntropy}(y_{\mathrm{Predict}}^{i}, y_{\mathrm{Truth}}) \\
&\qquad + \alpha\,\mathrm{KLD}(y_{\mathrm{Predict}}^{i}, y_{\mathrm{Predict}}^{C})\Bigr)
\end{aligned}
\tag{12}
$$

$$
\begin{aligned}
L_{\mathrm{FeatEncoder}}^{i}
&= \left\|F_{\mathrm{Encoder}}^{i} - F_{\mathrm{Encoder}}^{C}\right\|_{2}^{2} \\
L_{\mathrm{TotalWithFeature}}
&= \sum_{i=1}^{C} \mathrm{loss}_{i} \\
&= \sum_{i=1}^{C} \Bigl((1-\alpha)\,\mathrm{CrossEntropy}(y_{\mathrm{Predict}}^{i}, y_{\mathrm{Truth}}) \\
&\qquad + \alpha\,\mathrm{KLD}(y_{\mathrm{Predict}}^{i}, y_{\mathrm{Predict}}^{C}) \\
&\qquad + \lambda\,L_{\mathrm{FeatEncoder}}^{i}\Bigr)
\end{aligned}
\tag{13}
$$

6.2.1 데이터 증분 검증
본 실험에서 사용하는 Pothole 데이터셋은 총 681개의 이미지로 구성되어 있다.
이는 딥러닝 모델이 학습을 하는데 매우 적은 데이터 이므로 학습의 효과를 올리기

을 진행 하였다. 증분된 데이터와 원본 데이터는 모두 전처리 과정에서 모두 32x32

ABSTRACT
Improving Model Performance through Deep Learning
Model Lightweighting Techniques and Research on the SDiT
Model Technology.
Jin-Wook Choi
Department of Software and Communications Engineering
The Graduate School of Hongik University
In recent years, the field of artificial intelligence and deep learning has
witnessed continuous advancements in models powered by large datasets
and powerful computing capabilities. The accumulation of big data and
advancements in hardware have contributed to the scalability and complexity
of deep learning models. While these models offer high performance and
accuracy, they also come with increased model size and computational
requirements.
To address these challenges, model compression techniques have emerged
as an important research topic. Model compression aims to transform deep
learning models into smaller and more lightweight forms, reducing model
- 51 -

size and improving inference speed. This enables efficient execution of deep
learning models even in resource-constrained environments. In this study, we
analyze and compare representative model compression techniques such as
Knowledge Distillation, Weight Pruning, and Quantization. Among these
techniques, Knowledge Distillation, which involves the transfer of knowledge
from a Teacher model to a smaller Student model, has shown superior
performance by preserving the accuracy and characteristics of the Teacher
model.
Furthermore, in recent years, Vision Transformer (ViT) models, which are
based on the Transformer architecture and designed to replace traditional
convolutional layers in computer vision tasks, have gained attention. ViT
models demonstrate excellent performance by leveraging the power of
Transformers for processing image data. However, ViT models suffer from
drawbacks such as a large number of parameters and high data
requirements, resulting in increased model size and training costs.
Therefore, in this study, we propose a new model called SDiT
(Self-Knowledge Distillation image Transformer) to overcome the limitations
of ViT models and achieve high performance even with limited data.
